2026-08-23 기준 실제 구현 상태를 설명합니다. 이 문서는 2026-08-23 전반 최적화·리팩토링 패스가 완료된 코드의 최종 상태를 다룹니다.

1. 프로젝트 목적

한국투자증권(KIS) 계좌의 보유 종목과 시장 지표를 GitHub Pages의 정적 대시보드로 보여주고, 개인 데이터는 GitHub OAuth로 인증한 Cloudflare Worker 비공개 API 뒤에 둡니다. KIS 일봉은 로컬 동기화 스크립트가, 실시간 체결은 Synology Docker 수집기가 Worker KV에 적재합니다.

5. 성능 정리 (2026-08-23)

  • 지표 캐싱: 단위 집계와 MA20/60/120·RSI를 심볼×단위별로 캐시하고 스냅샷 재적재 때만 무효화합니다. 스크롤 프레임마다 전체 일봉(수천 개)을 다시 계산하던 낭비를 제거했습니다.
  • 뷰포트 범위 계산: 가격 자동 스케일 대상을 객체 includes 순회(O(n·m)) 대신 인덱스 범위(chartViewportRange)로 계산합니다.
  • 재생성 생략: 데이터·단위·기간·확대·보이는 창이 모두 같으면 SVG innerHTML 재생성을 건너뜁니다.
  • 컨트롤 메모이제이션: 종목·단위·기간 버튼 행을 선택이 바뀔 때만 다시 그려 스크롤 중 포커스 상태가 유지됩니다.
  • pointermove 경량화: 크로스헤어 요소 참조와 봉 개수를 캐싱해 마우스 이동마다의 DOM 질의를 제거했습니다.

6. 보안 상태

영역상태설명
비밀값확인.env 미추적, 전체 Git 이력에서 실제 시크릿 값 부재 확인. 예시 파일만 빈 값으로 커밋됨.
OAuth확인state를 HttpOnly·Secure·SameSite=Lax·10분 쿠키로 검증, 허용 로그인 단일 계정, KV 쓰기 불필요.
세션확인HMAC-SHA256 서명 + 만료 검증. 토큰은 URL 프래그먼트 → sessionStorage 경유(개인 프로젝트 수용 결정).
CORS확인Pages 오리진 단일 허용.
XSS수정브로커 스냅샷 문자열(종목명·심볼)이 innerHTML/속성에 들어가던 지점을 esc()로 이스케이프. 나머지 값은 숫자·검증된 날짜만 렌더링.
수집 인증수용INGEST_TOKEN 비교가 상수 시간이 아니며, 공개 /v1/market에 플랫폼 수준 외 속도 제한 없음. 개인 규모에서 수용.
컨테이너수용collector 이미지가 root로 실행되지만 사내 Synology망 한정. 비밀값은 env_file 주입.

7. 남은 위험과 보류 항목

  • 분봉 UI는 2026-08-23 사용자 확정으로 재개하지 않기로 하여 분봉 저장 경로(backfill_intraday.py, Worker /v1/intraday 양방향)를 제거했습니다. KV에 남은 intraday:* 키는 Cloudflare 대시보드에서 수동 삭제할 수 있습니다.
  • 실시간 체결 수집기(NAS)와 /v1/realtime 경로는 프론트엔드 소비자가 없지만 그대로 유지하기로 수용했습니다.
  • sync_portfolio.py의 토스증권 연동은 사용자 승인으로 제거되었습니다. 재사용 시 이전 커밋을 참조해야 합니다.
  • 계좌 연간 수익률은 입출금 시계열이 없어 의도적으로 비활성 상태입니다.
  • 오래된 공개 커밋 이력에는 당시 식별자가 남아 있을 수 있습니다(이력 재작성은 별도 결정 사항).
